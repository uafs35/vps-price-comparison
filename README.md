## 流量计法差异：RackNerd 的 2T 别按 2T 用

搬瓦工只计出站流量，1TB 就是实打实的 1TB 出站额度，从外面下载进 VPS 的数据不占额度；RackNerd 是进出站合计，标称 2T 指上行加下行的总和。

这个差异的实际影响取决于你的进出比例。建站、代理浏览这类出站占大头的用途，RackNerd 的实际出站额度仍然可观；但进出对称的流量，RackNerd 标称 2T 的实际可用量会落到 1T 附近，和搬瓦工的 1TB 持平。要是你的用途入站很多——异地备份、频繁往服务器同步文件、做种——RackNerd 的额度消耗会比数字看起来快得多，这种场景下搬瓦工“只计出站”的算法反而更经用。
